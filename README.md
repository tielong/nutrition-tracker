# 宝宝营养记录 🍼

一个简单的本地网页应用，用来记录宝宝每餐吃了什么，并按营养分类分析摄入的均衡与多样性。

## 功能

- **记一餐**：用自由文本快速记录，例如 `牛奶(200ml)，鸡蛋(1个)，香蕉(半个)`，应用会自动解析出「食物 + 份量」。支持中文全角括号（）和逗号、顿号等分隔符。
- **自动分类**：每种食物映射到一个或多个分类 —— **碳水 / 蛋白质 / 纤维 / 维生素 / 乳制品 / 脂肪**。内置常见婴幼儿食物，遇到新食物时会提示你一次性选择分类，映射表随使用逐渐扩充。
- **概览**：今日餐数与分类覆盖、本周各分类均衡、每日趋势图、食物丰富度，以及「本周新尝试」（方便追踪辅食首次添加，留意过敏反应）。
- **历史**：按日期查看、编辑、删除每一条记录。
- **食物**：管理食物与分类的映射，随时增删改。
- **设置**：宝宝昵称与出生日期（自动显示月龄）、数据导出/导入备份、清空数据。

数据仅保存在本地浏览器（localStorage），不上传任何服务器。建议定期在「设置」里导出 JSON 备份。

## 运行

```bash
npm install
npm run dev      # 本地开发，浏览器打开提示的地址
npm run build    # 生成生产版本到 dist/
npm run preview  # 预览生产版本
```

要求 Node.js 18+。

## 声明

本工具仅用于记录食物分类的多样性，供家长自行参考，**不构成任何医疗或膳食建议**。关于宝宝营养的具体问题，请咨询儿科医生。
